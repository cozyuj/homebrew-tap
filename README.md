# cozyuj/homebrew-tap

Homebrew tap for [AI Office](https://github.com/cozyuj/AI-office): an isometric office that shows your Claude Code sessions in real time.

```bash
# macOS app (Apple Silicon, menu bar, auto-updates)
brew install --cask cozyuj/tap/ai-office

# Web version CLI (any Mac, needs Node from Homebrew)
brew install cozyuj/tap/claude-ai-office
ai-office
```

The cask and formula are updated by `scripts/update-homebrew.js` in the AI Office repository after each release.
